# 🏦 Bank Customer Churn Analysis – Power BI Dashboard

📌 Project Overview

Customer churn is a major concern in the banking industry, as retaining existing customers is more cost effective than acquiring new ones.
This project focuses on analyzing bank customer churn patterns using Power BI, providing interactive insights into customer behavior, demographics, and financial 
attributes to support data driven retention strategies.

## 🎯 Objectives

Analyze overall customer churn rate

Identify key factors influencing customer churn

Visualize churn trends across demographics, products, and regions

Support business decisions with interactive dashboards

## 📊 Key Metrics

Total Customers: 4,204

Customers Lost: 810

Churn Rate: 19.27%

🧩 Dashboard Features

Churn Status slicer (Churned / Not Churned)

KPI cards for Customers, Customers Lost, and Churn Rate

Customer distribution by:

Gender

Activity Status

Number of Products

Credit Card Ownership

Country

Churn analysis by:

Age Groups

Credit Score Groups

Account Balance

Power BI

Data Cleaning & Modeling

Data Visualization

## 📌 Insights & Findings

Inactive customers show higher churn rates

Customers with fewer products are more likely to churn

Credit card ownership improves customer retention

Certain countries contribute more to churn

High balance customers also present churn risk

## 💡 Business Recommendations

Increase customer engagement programs

Promote cross selling of banking products

Target inactive customers with retention campaigns

Implement region specific retention strategies

Monitor high value customers proactively
